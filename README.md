# 🌐 Primeiro Site

Projeto desenvolvido durante meus estudos de **desenvolvimento web**, utilizando **HTML, CSS e JavaScript**, como parte da prática realizada no curso **"Crie um site simples usando HTML, CSS e JavaScript"**, da **Fundação Bradesco – Escola Virtual**.

O projeto foi desenvolvido com o objetivo de colocar em prática os conceitos apresentados durante o curso e dar os primeiros passos na criação de páginas web.

## 📚 Sobre o curso

O projeto foi desenvolvido acompanhando o curso **Crie um site simples usando HTML, CSS e JavaScript**, disponibilizado pela [Fundação Bradesco – Escola Virtual](https://www.ev.org.br/cursos/crie-um-site-simples-usando-html-css-e-javascript).

O curso apresenta conceitos fundamentais de desenvolvimento web, incluindo a estrutura de páginas HTML, estilização com CSS e introdução à interatividade com JavaScript.

## 🛠️ Tecnologias utilizadas

* **HTML5** — estrutura da página
* **CSS3** — estilização e organização visual
* **JavaScript** — funcionalidades e interatividade

## 📁 Estrutura do projeto

```text
primeiro-site/
├── index.html
├── main.css
└── app.js
```

### `index.html`

Responsável pela estrutura e pelos elementos da página.

### `main.css`

Contém os estilos utilizados para definir a aparência e a organização visual do site.

### `app.js`

Arquivo destinado às funcionalidades e interações desenvolvidas com JavaScript.

## 🎯 Objetivos

* Praticar a estrutura básica do HTML;
* Aprender a aplicar estilos utilizando CSS;
* Ter contato inicial com JavaScript;
* Entender como HTML, CSS e JavaScript trabalham juntos;
* Criar meu primeiro projeto de desenvolvimento web;
* Começar a construir um portfólio de projetos.

## 📖 Aprendizados

Este projeto fez parte dos meus primeiros estudos em desenvolvimento web e serviu como uma oportunidade para transformar os conceitos apresentados no curso em uma aplicação prática.

Além do aprendizado das tecnologias, o projeto também ajudou a desenvolver familiaridade com a organização de arquivos, edição de código e utilização do **Visual Studio Code**.
